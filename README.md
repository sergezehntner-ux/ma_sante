# Ma Santé v0.2.3.1 — Compendium v1

Base : v0.2.2.9. La branche de réparation PDF v0.2.3.0 n'est pas utilisée.

Corrections
- Traitements : le masque d’édition retrouve de nouveau les produits après la requalification des types personnalisés.
- Les compléments et produits médicaux déjà utilisés comme traitements restent sélectionnables ; les prestations de soins évidentes sont exclues.

Compendium v1
- Nouvelle rubrique Compendium.
- Affiche uniquement les entrées de Pharmacie dont le type personnalisé est exactement « Médicament ».
- Fiche médicament avec principe actif, indication documentaire, source et version documentaire.
- Bouton Pharmacovigilance depuis le Compendium et depuis la fiche Pharmacie d’un médicament.
- Avertissement permanent : « Informations documentaires uniquement — Ma Santé ne pose aucun diagnostic et ne recommande aucune modification de traitement. »
- Trois groupes toujours visibles :
  1. Selon Notice d’emballage & Swissmedic
  2. Selon OMS & associations médicales
  3. Provenant de sources inconnues ou non vérifiées
- Un groupe non renseigné affiche exactement « Pas d'informations disponibles. »
- Aucune modification directe du Compendium par l’utilisateur.
- Bouton de soumission préparé, mais aucun envoi n’est encore activé.

Contenu documentaire initial
- Rosuvastatin-Mepha sert de médicament pilote.
- Groupe 1 : synthèse prudente à partir de l’information professionnelle SwissmedicInfo.
- Groupe 3 : synthèse du document fourni « Médicaments -statine.docx ».
- Groupe 2 : pas d’informations disponibles.
- Les autres médicaments sont visibles dans le Compendium mais leur contenu documentaire détaillé reste à alimenter source par source.

La clé de données utilisateur reste inchangée : ma-sante-v02001.
