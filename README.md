# Ma Santé v0.1.6

Nouveautés terrain :
- identité visuelle bleue ;
- Aujourd'hui et Traitements plus compacts ;
- + Ajouter aligné avec Mes traitements ;
- dose réellement prise modifiable au moment de valider ;
- vraie section Pharmacie distincte des Traitements ;
- bouton « + Pris au besoin » dans Aujourd'hui ;
- la prise au besoin choisit uniquement un produit de Pharmacie puis demande quantité, unité, date, heure et note ;
- toute prise est ajoutée à l'historique ;
- stock décrémenté selon la quantité réellement enregistrée ;
- périodicité quotidienne, certains jours de semaine ou certains jours du mois ;
- listes Unité, Raison et Instructions dynamiques : seulement les termes déjà enregistrés + « Autre… » ;
- un nouveau terme saisi via « Autre… » apparaît dans les prochaines listes ;
- reprise automatique des données v0.1 à v0.1.5.
