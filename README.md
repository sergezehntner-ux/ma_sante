# Ma Santé v0.1.1

Prototype PWA terrain.

Fonctions incluses :
- Aujourd’hui : prises regroupées par heure, validation individuelle ou groupée.
- Traitements : nom, dosage, raison, instruction, dates, stock, péremption, photo facultative.
- Posologie actuelle : plusieurs heures et quantités par jour.
- Semainier : génération automatique sur 7 jours depuis la posologie actuelle, préparation par médicament.
- Sauvegarde : export/import JSON manuel, adapté à un transfert via OneDrive.
- Fonctionnement local : les données sont conservées dans le navigateur (localStorage).

## Lancer sur GitHub Pages
1. Décompresser le ZIP.
2. Copier les fichiers à la racine d'un dépôt GitHub.
3. Activer GitHub Pages sur la branche principale.
4. Ouvrir l'URL Pages sur smartphone/notebook puis installer la PWA.

## Important
Cette v0.1.1 est un prototype de gestion personnelle. Elle ne remplace pas un médecin ou un pharmacien.
Avant d'utiliser des données importantes, effectuer régulièrement un export de sauvegarde.

## Limites volontaires de v0.1.1
- Pas encore d'import du référentiel suisse complet.
- Pas encore d'historisation avancée des changements de posologie.
- Pas encore de stock par boîte ni mouvements automatiques.
- Pas encore d'ordonnances/rapports/alertes.
- Pas encore de chiffrement applicatif.
